# NitroGen: Generalist Gaming Agents

A research project on training generalist gaming agents from public internet streams.

## Features

- Fully automated pipeline for extracting training data from gameplay videos
- Controller detection and action parsing using computer vision
- Zero human labeling required
- Trained on 1,000+ games across multiple genres
